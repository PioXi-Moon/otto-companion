# Otto 语音展示语料库

共 320 句，按展示场景分组，完整数据在同目录的 `语音展示语料库.csv`。

## 最推荐的现场顺序

1. **开机与重逢**：`V002`、`V003`
2. **夸奖与得意**：`V021`、`V022`、`V033`
3. **傲娇与玩笑**：`V061`、`V062`
4. **关心与安慰**：`V081`、`V085`
5. **疲惫与低落**：`V101`、`V108`、`V119`
6. **明确动作**：`V261`、`V267`、`V271`、`V273`、`V275`、`V277`
7. **告别收尾**：`V310`、`V314`、`V320`

## 播放规则

- 标为 `S` 的句子反应最明显，适合面试、路演和录制视频。
- 说移动口令后，等 TTS 结束后至少 **6 秒**再继续下一句。期间重复说话会中断当前移动。
- 日常陈述也有保底 `confirm` 反馈，但展示身体动作时优先使用表情明确或命令明确的句子。
- 表格里的“动作方向”表示期望范围。当前本体允许同一反应在相近动作之间变化，以避免机械重复。
- 前进、后退、左转、右转、弹跳、扭动最好从“明确动作”和“极短口令”两组里选。
