# 第一阶段验证报告

时间：两周。范围：软件 Demo。验证对象：H2 —— **关系感来自记忆的连续，而不是回答质量**。

结论先说：**链路已经通了，关系感还没验。** 下面分开写。

## 一、通过标准是什么

一开始我把通过标准写成"测试者能主动说出它记得我"。后来发现这句话没法当标准用——
我随时可以引导他说出来。所以改成一个更硬的判据：**测试者说出"它记得我"的时候，
我有没有引导过。** 没有引导，才算数。

这条判据决定了后面很多东西：证据必须由它主动给，而不能靠我问出来。

## 二、已经证实的

### 记忆真的在跑

完整链路：对话 → 异步抽取记忆 → 判断互动类型 → 召回 → 注入下一轮 → 到点主动开口 →
用户回应 → 闭合成共同经历。这条链路上每一环都能单独关掉做对照：

```powershell
pnpm start                    # 起服务
node scripts/smoke.mjs        # 64 项自检，包含实时语音人格、动作语义与组合
```

自检覆盖的是"没有它这条假设就无从谈起"的部分：记忆能不能写进去、
线头会不会到点、关掉记忆之后召回是不是真的没了、人格推断有没有输出、埋点全不全。

**64 项全过。** 这不是产品完成的证明，是"仪器没有坏"的证明。

### 日记是这套系统里最难的一环，也最能看出真假

日记不是"让模型写段文字"，它是记忆的呈现形式：一天一页，它写给自己看。
我前后推翻了五版提示词，因为每一版都在犯同一个错——**把对话复述一遍**。
我自己读那几版的时候没有任何等待的理由：那些话我十分钟前刚说过。

最后定下来的规矩是硬的：一页里必须有"看见、串联、细节、悬念"四样里的至少两样。
看不见我看不见的那一层，这一页就是白写的。

光靠提示词治不住，所以加了一道能算的校验（`server/pagelint.mjs`）：

生成 → 按规则查 → 不过就把毛病原样念回去 → 重写一次。

规则里没有一条需要品味，全是能算的：平均句长、一问一答转了几处、有没有"我数过"这种清点句、
禁用词、正文里是不是出现了"你"、卡片是不是从正文里抠出来的、版式有没有跟昨天撞。

规则自己也有用例（`node scripts/smoke.mjs --static`），改规则会立刻知道有没有把好页误判成坏页。

实测拦下来的问题：句子太碎（平均一句 9 个字）、复述对话（转了 7 处）、
卡片和正文重复 8 个字以上、空白日硬凑了 240 字。都是真人一眼就会皱眉的地方。

### 出错的时候它是诚实的

生成慢会先出动作和"……我想想"；连不上接口会明说自己现在能干什么、不能干什么，
不假装正常。断网还卖萌是最糟的一种表现，这一条在方案里就写死了。

## 三、还没证实的

**关系感本身。** 这个 demo 能证明记忆是连续的、能证明它到点会主动开口，
证明不了人会不会因此产生关系感。那需要真人用几天。

所以我没说"验证成功"。现在的状态是：仪器造好了，还没放人进去。

## 四、做的时候发现的几件事

**降级对话不是削弱验证，反而让证据更干净。**
原来我把对话当主体，因为它是唯一的记忆入口。后来想明白：证据应该由它主动给。
现在对话被压到"使唤它"那一页的最下面，当一条通道；摸它、它的本子、
它给我留的卡片才是主界面。摸它时反应随关系阶段变，这是另一种证据，而且更身体化。

**三层提示词是必须的。**
说话的场合共用一层（身份、关系、四个特质、四条底线、说话方式），
日记、主动发起、对话各自叠一层。记忆抽取和人格推断**不套人格层**——
那两个是工程任务，JSON 里混进"傲娇"和"可爱"会直接影响输出质量。

**能算的规矩比文采要求有用。**
我一开始不停地改措辞，改到第七遍还是那几句。"别写成短句"这种话模型是有抗体的，
写成"平均句长不到 14 个字就重写"才有用。

**一个藏了很久的 bug 是用户视角才看得见的。**
桌宠的腮红写在 CSS 里，而那条 `display:none` 的规则同时也命中了宠物自己——
只要动作带腮红，整只就消失。"害羞"这个动作因此一直是隐形的，直到我给它加腮红才发现。
单看代码看不出来，因为每一处都"写得对"。

## 五、下一步
