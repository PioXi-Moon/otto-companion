# Otto 硬件动作语言

Otto 没有手，硬件表达只有四个舵机、一个 8×8 点阵和（可选）蜂鸣器。动作设计不能再把所有情绪
都压成“左右晃两下”，而要明确回答三个问题：

1. **第一眼看见什么表情**
2. **身体从哪个姿态走到哪个姿态**
3. **情绪最后停在哪里**

## 一拍的结构

每个动作按三拍组合：

```text
表情标点 → 身体动作 → 停顿/回落
```

例如：

```text
傲娇：单眼 → 转开 → 停住 → 转回来低头
亲近：爱心 → 摆动靠近 → 低头 → 开心回落
委屈：闭眼 → 低头 → 停住 → 恢复平静
```

动作之间不再只靠随机堆叠，而是用 `WAIT` 留出“反应时间”。没有停顿，连续指令会像机械执行；
有一次停顿，才像角色先愣住、再决定怎么回应。

## 情绪语法

| 情绪 | 表情 | 身体语法 | 收尾 |
|---|---|---|---|
| 开心 | HAPPY | 轻跳一次 + 摆身 | 回到 CALM |
| 得意 | STAR | 摆身 + 转身展示 | 回中，不持续嚣张 |
| 好奇 | CALM / SCAN | 低头靠近 + 扫描 | 单眼收尾 |
| 惊讶 | SURPRISE | 弹跳 + 扫描 | 单眼 |
| 亲近 | HEART | 摆动 + 低头 | HAPPY 后回 CALM |
| 害羞 | WINK | 低头 | HEART 一闪，再回 CALM |
| 傲娇 | WINK | 转开，停住 | 转回并低头 |
| 闹脾气 | ANGRY | 转身 | 坐下，但最后恢复 CALM |
| 委屈 | SLEEP | 低头 | 停住后恢复 CALM |
| 思考 | CALM | 矩阵旋转 + 低头 | 回 CALM |
| 开心庆祝 | STAR | 跳舞 + 矩阵波浪 + 扭动 | 开心收尾 |

## 组合与语音时序

语音回答正在播放时，固件会拒绝大部分身体动作。因此完整序列按下面的时序执行：

```text
表情/短动作先进入队列
→ TTS 播放
→ VOICE IDLE
→ 主动作
→ 副动作
→ 收尾动作
```

这一步由小智服务的 TTS 生命周期触发，不由固定 sleep 猜测。

## 已知边界

- 当前固件没有蜂鸣器，`SFX` 是可选步骤，缺失时跳过，不中断后续动作。
- 点阵只有单色 8×8，表情靠眼形、嘴形和闪烁节奏区分。
- 舵机动作有供电峰值限制，步行使用四舵机同步插值和较低幅度。
